# BYOK Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let authed users supply their own AI provider API keys (Anthropic, OpenAI, Google) stored encrypted (AES-256-GCM) in Postgres. Server AI consumers (CV import, CV translate, future AI agent) use a resolver that prefers BYOK over the shared server env keys. Anon flow untouched.

**Architecture:** New `UserAiKey` Prisma model (one row per user+provider). `byokCrypto` lib wraps Node `crypto` for encrypt/decrypt with a single `BYOK_MASTER_KEY` env var. New REST routes under `/api/v1/ai-keys` (GET/PUT/DELETE), `requireAuth`-gated. New `aiKeyResolver` consumed by existing cvImport / cvTranslate. Settings page at `/settings/ai-keys`.

**Tech Stack:** Bun + Hono + Prisma 7 + Postgres (Supabase) + Node `crypto` + React 19 + Vite + RHF + base-ui + Tailwind 4 + vitest + bun:test.

**Spec:** `docs/superpowers/specs/2026-05-07-byok-design.md`

## Task 2: Shared provider constants

**Files:**

- [ ] **Step 1:** Create `shared/src/aiKeys/providers.ts`:

```ts
export const AI_PROVIDERS = ["anthropic", "openai", "google"] as const;
export type AiProvider = (typeof AI_PROVIDERS)[number];

export const AI_KEY_PREFIX: Record<AiProvider, string> = {
  anthropic: "sk-ant-",
  openai: "sk-",
  google: "AIza",
};

export const AI_KEY_MIN = 20;
export const AI_KEY_MAX = 256;

export function isAiProvider(v: unknown): v is AiProvider {
  return typeof v === "string" && (AI_PROVIDERS as readonly string[]).includes(v);
}

export function validateKey(provider: AiProvider, key: string): { ok: true } | { ok: false; reason: string } {
  if (key.length < AI_KEY_MIN || key.length > AI_KEY_MAX) {
    return { ok: false, reason: `Longueur invalide (${AI_KEY_MIN}–${AI_KEY_MAX}).` };
  }
  if (!key.startsWith(AI_KEY_PREFIX[provider])) {
    return { ok: false, reason: `Doit commencer par "${AI_KEY_PREFIX[provider]}".` };
  }
  return { ok: true };
}
```

## Task 3: Crypto module

**Files:**
- Create: `server/src/lib/byokCrypto.ts`
- Create: `server/src/lib/__tests__/byokCrypto.test.ts`

- [ ] **Step 1:** Create `server/src/lib/byokCrypto.ts`:

```ts
import { createCipheriv, createDecipheriv, randomBytes } from "node:crypto";

const ALGO = "aes-256-gcm";
const IV_LEN = 12;
const KEY_LEN = 32;

function loadMasterKey(): Buffer {
  const raw = process.env.BYOK_MASTER_KEY;
  if (!raw) throw new Error("BYOK_MASTER_KEY is not set.");
  const buf = Buffer.from(raw, "base64");
  if (buf.length !== KEY_LEN) {
    throw new Error(`BYOK_MASTER_KEY must decode to ${KEY_LEN} bytes (got ${buf.length}).`);
  }
  return buf;
}

let cachedKey: Buffer | null = null;
function masterKey(): Buffer {
  if (!cachedKey) cachedKey = loadMasterKey();
  return cachedKey;
}

export type EncryptedKey = { ciphertext: Buffer; iv: Buffer; authTag: Buffer };

export function encrypt(plain: string): EncryptedKey {
  const iv = randomBytes(IV_LEN);
  const cipher = createCipheriv(ALGO, masterKey(), iv);
  const ciphertext = Buffer.concat([cipher.update(plain, "utf8"), cipher.final()]);
  const authTag = cipher.getAuthTag();
  return { ciphertext, iv, authTag };
}

export function decrypt(rec: EncryptedKey): string {
  const decipher = createDecipheriv(ALGO, masterKey(), rec.iv);
  decipher.setAuthTag(rec.authTag);
  const plain = Buffer.concat([decipher.update(rec.ciphertext), decipher.final()]);
  return plain.toString("utf8");
}

export function lastFour(plain: string): string {
  return plain.slice(-4);
}

// For tests only — resets the cached key after env mutation.
export function _resetForTests(): void {
  cachedKey = null;
}
```

```ts
export type ResolvedKey = { key: string; source: "byok" | "server" };

const ENV_KEY: Record<AiProvider, string> = {
  anthropic: "ANTHROPIC_API_KEY",
  openai: "OPENAI_API_KEY",
  google: "GOOGLE_API_KEY",
};

export async function resolveProviderKey(
  userId: string | null,
  provider: AiProvider,
): Promise<ResolvedKey | null> {
  if (userId) {
    const byok = await getDecryptedKey(userId, provider);
    if (byok) return { key: byok, source: "byok" };
  }
  const envKey = process.env[ENV_KEY[provider]];
  if (envKey) return { key: envKey, source: "server" };
  return null;
}
```

## Risks / open questions during build

- **Bytes columns in Prisma + Postgres:** Prisma maps `Bytes` → `bytea`. Confirm migration SQL is `BYTEA`, not `BLOB`. If Supabase shows column issues, switch to base64 `Text` columns and re-test (no behavior change, just storage shape).
- **Rate-limit middleware reuse:** if existing per-user rate limiter doesn't exist, keep it scoped to BYOK PUT only — don't yak-shave a generic limiter in this ticket.
- **Provider selection for authed users with multiple BYOK keys:** out of scope. Server stays on `AI_PROVIDER` env, resolver just sources whichever provider the route picks. Future ticket can add per-user default.
